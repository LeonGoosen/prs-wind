CRITICAL CORRECTIONS FROM v3.6.1 SECOND DIAGNOSTIC:
- Removed double application of wind angle. Solver MIN/MAX holds are treated as already angle-corrected at the displayed baseline Target WD.
- Wind Angle Calibration B now supplies the rifle/ammo angle-response curve; ideal sine response is only the fallback.
- Wind Speed Calibration A is used as the full-value fallback when the baseline Target WD is close to the bore line.
- Target DOF Validation D now contributes a confidence penalty when the stored solver WD convention does not validate.
- Ballistics and the probability engine now use the same target-specific fused direction state.
- Pre-shoot snapshots freeze the exact Accuracy Core 4 output seen by the shooter.
- Existing matches calculate from frozen rifle/ammo snapshots, not editable/deletable current profiles.
- L/R ambiguity is derived from Monte Carlo sign probability.
- Match learning shifts the required-hold distribution before optimization.
- Hysteresis uses a floating-point-safe 0.1-mil comparison and recalculates probability for a retained hold.
- MV is normalized to fps internally for solver response coefficients.
- DA uncertainty is not stacked on top of temperature/pressure uncertainty.
- Partial solver response coefficients replace only the dimensions actually supplied.
- Raw stage telemetry is separated into IndexedDB rather than growing the main localStorage object.
- Calypso stage ownership is tagged per sample and pending samples are flushed before stage switching.
- Live preview uses 500/750/1000 samples based on target count; SHOOT and frozen stage calls retain 10,000 samples.
- Calypso pairing persists the exact granted device ID and no longer reconnects to an arbitrary ds[0].
- Data Service presence is detected but not decoded without the official protocol contract.
