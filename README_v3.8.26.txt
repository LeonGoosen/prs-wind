WIND SIGHT PRS v3.8.26 — Average Window Summary

Scope
- Environmental-summary update only.
- LOW AVG = lowest saved window AVG.
- BEST AVG = median of saved window AVGs.
- HIGH AVG = highest saved window AVG.
- RAW observed extremes retain the lowest saved MIN and highest saved MAX.
- Per-window MIN↔AVG and AVG↔MAX spacing is displayed as descriptive spread/asymmetry information.
- Existing vector/coherence direction summary retained.
- Legacy firing-solution, probability, calibration and hold-generation algorithms are not changed by this release.

Deployment
Keep the existing repository, Worker, URL, Cloudflare build/deploy commands and Safari/PWA installation. Export a populated JSON backup before deployment. Do not clear browser storage or remove the Home Screen app.
