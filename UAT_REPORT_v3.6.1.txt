FIXED FROM v3.6.0
- Restored the missing SHOOT runtime helper.
- Isolated live Calypso data by stage session.
- Removed destructive 120-second raw-data truncation.
- Raw stage telemetry is retained and persisted in 2.5-second batches.
- Heavy prediction/render is throttled to a maximum of 2 Hz.
- Whole-app autosave no longer runs on every sensor event.
- Calypso direction is excluded until a global sensor reference bearing is explicitly set.
- Ballistics shows Measured Target WD separately from WIND SIGHT Fused Target WD.
- Solver MIN/MAX tail clamping replaced with bounded local extrapolation and a confidence penalty.
- Sampled range now changes target angular geometry.
- Optional solver-derived response coefficients added for wind/range, elevation/range, wind/MV, elevation/MV and elevation/DA.
- Missing response coefficients reduce model confidence.
- Match learning now uses signed L/R holds.
- Match learning requires Confirmed or Approximate working-hold quality; Unknown is excluded.
